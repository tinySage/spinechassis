# Spine Chassis

A 3D atlas of the human spine under load: CT segmentation, biomechanics and an interactive viewer.

**In development.**

## Phases

- [ ] Phase 1 · Data — VerSe 2020 acquisition, prep, demo case selection
- [ ] Phase 2 · Segmentation — MONAI 3D U-Net training and evaluation
- [ ] Phase 3 · Meshing — cleanup, smoothing, decimation, compression
- [ ] Phase 4 · Biomechanics — geometry, load model, validation
- [ ] Phase 5 · Viewer — Three.js atlas, landing page
- [ ] Phase 6 · Ship — polish, performance, accessibility, deploy
